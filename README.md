## 🚀 Featured Project

### DevQuest

**Gamify your developer journey.**

A full-stack gamification platform designed to turn development goals into quests, progress, XP, streaks, achievements, and leaderboards.

**Stack:**
Next.js • React • TypeScript • Tailwind CSS • Zustand • Node.js • Express • Prisma • PostgreSQL

**Highlights:**

- Authentication with access & refresh tokens
- HttpOnly & Secure cookies
- Quest management and progress tracking
- XP and level system
- Daily streaks
- Achievements
- Leaderboard
- Role-based behavior
- PostgreSQL database with Prisma
- REST API
- Responsive UI
- Deployed frontend and backend

🔗 **Live Demo:** https://devquesti.netlify.app
🔗 **GitHub:** https://github.com/Unstvii/DevQuest
